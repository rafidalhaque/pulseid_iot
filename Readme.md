# PulseID
> Attendance and Access Control with esp32

## Hardware
1. esp32
2. breadboard
3. relay module
4. jumper wires (min. 6)

## Reserved Hardware
1. LED (2 Green, 2 Red)
2. OLED 0.96
3. Capacitor
4. Resistor

## Connection
1. esp:3v3 <-> relay:VCC
2. esp:GND <-> relay:GND
3. esp:D5 <-> relay:IN
